# Starfall Frontier 🚀

An original 2D side-scrolling action roguelite RPG built with **Godot Engine 4.x** in 100% GDScript.

![Godot Engine 4](https://img.shields.io/badge/Godot-4.x-blue.svg)
![Language](https://img.shields.io/badge/Language-GDScript-green.svg)

---

## 🎮 Features

- **Action Platformer Combat**: Fast-paced movement, double jumps, coyote time, jump buffering, and dash invulnerability frames.
- **5 Operative Origins**: Choose from Vanguard, Scout, Engineer, Mystic, and Nomad archetype origins with distinct stat bonuses.
- **Dynamic Rarity & Weapons**: Data-driven weapon modifier engine (Common → Mythic) with damage types (Physical, Energy, Fire, Ice, Void). Switch weapons on the fly with `Q`/`Tab`.
- **5 Enemy Archetypes**: Battle Ash Beetles, Frost Stalkers (ranged), Void Lurkers (ambushers), Iron Golems (tanks), and Swarm Drones.
- **World Instability Escalation**: Planetary risk meter that mutates enemies into golden Elites as instability rises.
- **10-Second Extraction Channeling**: Reach the exit beacon and hold the perimeter to secure run credits and materials.
- **Expedition Base Hub**: Upgrade stations, manage persistent profile data, and launch new planet runs.
- **JSON Save System**: Atomic writes with backup protection and version migration.

## 🕹️ Controls

| Action | Primary Key | Secondary |
|:---|:---|:---|
| Move Left / Right | `A` / `D` | `Left` / `Right` Arrow |
| Jump / Air Jump | `Space` | `W` / `Up` Arrow |
| Dash (i-frames) | `Shift` | `J` |
| Attack | `Left Mouse Click` | `K` / `Z` |
| Switch Weapon | `Q` | `Tab` |
| Interact | `E` | — |
| Inventory & Profile | `I` | — |

## 🚀 Getting Started

1. Download **Godot Engine 4.x (Standard 64-bit)** from [godotengine.org](https://godotengine.org/download).
2. Open Godot Engine and click **Import**.
3. Select `project.godot` inside this directory.
4. Press **`F5`** (or the **Play ▶** button) to launch!
