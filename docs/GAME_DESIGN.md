# Game Design Document - Starfall Frontier

## Title
**STARFALL FRONTIER**

## Tagline
"Explore hostile procedural worlds, gather ancient star-shards, defeat mutated guardians, and build an empire across the shattered frontier."

## Gameplay Pillars
1. **Exploration**: Procedural planets with unknown caves, ancient ruins, hazardous ecosystems, and high-value resource nodes.
2. **Fast Action Combat**: Skill-focused platforming combat with iframe dashes, elemental status interactions, and satisfying feedback.
3. **Risk vs Reward**: Extraction mechanics where deeper exploration yields mythic loot but escalates World Instability and enemy hostility.
4. **Build Synergy**: Combine Origins (Vanguard, Scout, Engineer, Mystic, Nomad), Data-driven Weapons, Relics, and Autonomous Companion Drones.
5. **Meaningful Meta-Progression**: Run deaths reset temporary gear but retain research shards, permanent base unlocks, companion blueprints, and new origins.

## Originality Mechanics (Differentiators)
1. **World Instability Meter**: Environmental stability degrades over run time, mutating enemies into elites while spawning hyper-rare resources.
2. **Relic Fusion System**: Combine three raw relic shards into customized combat singularies (e.g. Fire + Void + Crystal = Molten Singularity).
3. **Expedition Contracts**: High-risk optional contracts selected before deployment (e.g. "No Healing", "Extract within 10 minutes", "Melee Only") offering bonus rewards.
